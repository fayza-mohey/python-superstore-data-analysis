# Superstore Sales Data Analysis

## Project Overview
This project explores Superstore sales data to understand business performance, analyze profitability, and identify trends and patterns that can support data-driven decision-making.

## Objectives
- Analyze sales and profit performance.
- Compare performance across product categories, regions, and customer segments.
- Explore sales trends over time.
- Examine relationships between sales, profit, and other numerical variables.
- Calculate key business performance indicators (KPIs).

## Tools & Technologies
- **Python**
- **Pandas** – Data manipulation and analysis
- **NumPy** – Numerical operations
- **Matplotlib** – Data visualization
- **Seaborn** – Statistical visualization
- **Jupyter Notebook** – Interactive analysis

## Project Workflow
1. Data loading and inspection
2. Data cleaning and duplicate checking
3. Exploratory Data Analysis (EDA)
4. Feature engineering
5. Sales and profitability analysis
6. Trend analysis and visualization
7. KPI calculation
8. Exporting cleaned data

## Key Analysis Areas
- Sales and profit distribution
- Category and regional performance
- Customer segment analysis
- Sales trends over time
- Profit margin and shipping duration
- Business KPIs

## Project File
`Superstore_Analytics_Final.ipynb` contains the Python analysis and visualizations.

## Purpose
This project demonstrates practical data analysis skills, including data preparation, exploratory analysis, feature engineering, and visualization, to generate insights from business data.
